GifForge — GIF Guide

Turn frame-by-frame PNGs into GIFs (Windows PowerShell + free CLI tools)

← Open the browser GIF maker

Your situation PNG frames

You don't have an input.mp4 — you have a folder of PNG images, one per frame (FNF THINK style). The tools below take those PNGs directly and turn them into a GIF. No video needed.

Recommended tool: gifski — 100% free, command-line, high quality, works great with numbered PNG sequences. No FFmpeg required.

Step 1 — Get the gifski CLI (already done)

Important: the winget/MSI version of gifski is the GUI app — it opens a window and does NOT work from the command line. You need the CLI binaries from https://gif.ski/.

I already downloaded the correct CLI for you into gifski-cli\win\gifski.exe. The scripts use it automatically. To verify:

.\gifski-cli\win\gifski.exe --version

(Should print gifski 1.32.0. If you ever need to re-download: https://gif.ski/gifski-1.32.0.zip → extract into a gifski-cli folder.)

Step 2 — Put your frames in a folder

Example layout inside this project:

gif-tool\
  frames\
    frame0001.png
    frame0002.png
    frame0003.png
    ...

Numbered names like frame0001.png are best — they keep the correct animation order.

Step 3 — Make the GIF (clean, recommended)

The full pipeline. It cleans semi-transparent noise first, then encodes:

.\make-clean-gif.ps1

This does two things:

  1. clean-frames.ps1 — binarizes alpha (≥200 → opaque, else transparent) into frames-clean/. Fixes the noise / white-bleeding issue.
  2. make-clean-gif.ps1 — runs gifski on frames-clean\*.png → output-clean.gif.

Simple version (faster, less cleanup):

.\make-gif.ps1

Uses bundled CLI → output.gif. Full resolution, may keep minor edge noise.

With speed / size options (clean):

.\gifski-cli\win\gifski.exe --fps 24 -o .\output-clean.gif .\frames-clean\*.png
  • --fps 24 — playback speed (browsers cap at 50 fps)
  • omit --width to keep original size (best quality)

Why it looked blurry before: the old script forced --width 480, shrinking your 531px frames. It's now set to keep the full 531x650 resolution.

Step 4 — Renumber messy frames (if needed)

If your PNGs have random names, run this in PowerShell first:

$i = 1
Get-ChildItem .\frames\*.png | Sort-Object Name | ForEach-Object {
    Rename-Item $_.FullName ("frame{0:D4}.png" -f $i)
    $i++
}

Then run the make-gif / make-clean-gif command from Step 3.

Step 5 — Speed / FPS

To make it faster, change the FPS and re-run:

# In make-clean-gif.ps1 / make-gif.ps1:
$Fps = 12   # change to 24, 30, etc.

# Or via CLI:
.\gifski-cli\win\gifski.exe --fps 24 -o .\output-clean.gif .\frames-clean\*.png
  • --fps 24 — playback speed (browsers cap at 50 fps)
  • Faster = higher FPS (e.g. 24, 30)
