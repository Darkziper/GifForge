Make the GIF with GifForge Browser

You don't need any install — the maker runs entirely in your browser (no uploads, no server, no build step). Just open the GIF maker and:

  1. Drop in your PNG frames — or pick them with the file browser. Files are sorted automaticly by the website, so numbered sequences land in the right order.
  2. Set the frame delay / FPS, loop count, max width, colors, and background.
  3. Hit Create GIF, wait for the Web Worker to encode, then Download GIF.

Transparent GIF output: semi-transparent pixels are binarized at alpha ≥ 200, which removes the fuzzy edge noise and white bleed that GIF encoders produce from soft PNG alpha.

Tips Quality

  • Auto naming GifForge sorts uploads by name and auto-renames them to frame0001.png, frame0002.png, etc., so you don't have to rename files manually.
  • Speed. Browsers cap GIF playback around 50 fps; keep frame delay at or above ~20 ms. The maker's FPS presets (10/15/24/30) handle this.
  • Clean output. If the sprite had no transparency, pick a solid background (Black / White / Dark / Custom) under Background — it avoids fringe entirely.
